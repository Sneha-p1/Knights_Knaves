# 🏰 Knight & Knave: The Logic Quest

A fantasy-themed logic puzzle game where players explore a kingdom, solve character-statement puzzles, and identify each character as a **Knight**, **Knave**, or **Spy**.

## 🎮 About the Game

In Knight & Knave, each character has a statement that helps you determine their role:

- **Knight ⚔️** — always tells the truth.
- **Knave ☠️** — always lies.
- **Spy 🕵️** — may tell the truth or lie.

Choose a role for every character, check your verdict, and progress through increasingly challenging trials.

## ✨ Features

- Fantasy-inspired interface with a medieval color palette.
- Responsive layout designed with mobile play in mind.
- Three difficulty levels: Easy, Medium, and Hard.
- Logic puzzles featuring one or more characters.
- Hints to help you reason through a puzzle.
- Score points for correct answers.
- Player name and rank display.
- Level progression and unlockable stages.
- Achievement badges.
- Sound effects for clicks, correct answers, and incorrect answers.
- Animated falling-snow background and confetti celebration.

## 🚀 Getting Started

## How to Run

1. Open the project folder in VS Code.
2. Open `code.html`.
3. Click **Go Live** using the Live Server extension.

Alternatively, open `code.html` in a web browser.

## 🕹️ How to Play

1. Select **Play Game** on the intro screen.
2. Enter a detective/player name.
3. Select an unlocked level from the Kingdom Map.
4. Read each character's statement carefully.
5. Assign each character a role: Knight, Knave, or Spy.
6. Select **Check Logic** to submit your answer.
7. Use **Show Hint** if you need help. Puzzles solved with a hint award fewer points.
8. Select **Next** to continue to the next puzzle.
9. Complete a level to unlock the next stage.

## 🏆 Scoring and Progress

- Correct answer without a hint: **10 points**.
- Correct answer after using a hint: **5 points**.
- Your rank increases as your score grows.
- Achievements can be earned by solving puzzles without hints and completing the final level.

## 🧠 Logic Rules

- **Knight:** the character's statement must be true.
- **Knave:** the character's statement must be false.
- **Spy:** the character may tell the truth or lie.

## 📌 Notes

- Google Fonts requires an internet connection to load the selected fonts; fallback fonts are defined.
- Sound playback may require a user interaction before the browser enables audio.
- The project uses browser-side HTML, CSS, and JavaScript; it does not require a backend server.
